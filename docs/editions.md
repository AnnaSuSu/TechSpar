# 社区版与官方版本

| 项目 | 社区源码 | 官方网站 / v0.4.0 起的官方桌面端 |
| --- | --- | --- |
| 代码来源 | 本公开仓库 | 独立私有仓库 |
| 部署方式 | 自行部署，可自行构建本地桌面端 | 网站运行云服务，桌面端连接 techspar.cn |
| 模型配置 | 自己配置 API Key | 只使用平台服务和套餐 |
| 用户与记录 | 保存在自己的部署中 | 使用官方云账户，网站和桌面共享数据 |
| 官方支付与订阅实现 | 不包含 | 由官方服务维护 |
| 赞助入口 | 保留，支持项目开发 | 提供套餐购买与额度展示 |

公开仓库继续维护社区功能与修复，不直接合并私有仓库的提交或目录。需要共享的修复经过逐项检查后独立移植。

官方桌面安装包在私有 CI 构建，只把安装文件和校验和传到本仓库 Releases。公开仓库不再运行官方安装包发布工作流，避免覆盖商业版产物。

GitHub 自动附带的 Source code 压缩包始终对应社区源码。它与官方安装包不是同一版本形态。v0.3.2 及更早的安装包和源码标签作为历史版本保留，不会自动变成云客户端；旧本地数据也不会自动上传。
