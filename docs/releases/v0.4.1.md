# TechSpar v0.4.1 — 桌面面试 Copilot

- 桌面端分别采集麦克风与系统音频，直接区分自己和对方，无需录入声纹。
- 实时转写接入 Qwen 流式 ASR，回答使用独立的 DeepSeek 官方模型配置。
- 回答流式显示，新问题会取消上一题未完成的回答；断线或设备中断时停止采集。
- 网页 Copilot 入口直接引导下载桌面端。

## 安装包

官方 macOS Apple Silicon 与 Windows x64 安装包由商业库构建，连接 techspar.cn 并使用官方云账户。GitHub 自动附带的 Source code 对应社区源码，适合自行部署。密钥仅保存在服务端，不包含在安装包中。

macOS 首次使用需允许麦克风及系统音频录制，Windows 需允许麦克风访问。建议使用耳机，并在开始前确认两路音量。当前安装包未进行商业签名或 macOS 公证，系统可能显示安装提示。
