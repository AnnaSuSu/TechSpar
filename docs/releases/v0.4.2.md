# TechSpar v0.4.2 — 语音输入反馈修复

- 模拟面试和专项训练在麦克风权限不足、设备不可用、录音中断或语音识别失败时显示明确提示。
- 录音内容过少或未识别到语音时给出重试提示。
- 录音时提示再次点击麦克风停止并转成文字。
- 录音启动失败和离开页面时清理麦克风资源。

## 安装包

提供 Windows x64 EXE、macOS Apple Silicon DMG 和 ZIP。官方桌面端连接 techspar.cn；现有客户端重新打开页面后也可使用更新后的语音输入提示。

安装包未进行商业签名或 macOS 公证。SHA256SUMS.txt 提供下载文件校验值。
